# DuckDuck Club Landing

Minimal Next.js app scaffolded with reusable components and route-based structure.

## Structure

- `app/`: Route entries (`/` and `/access`) and root layout.
- `components/layout`: Header/footer shared across routes.
- `components/sections`: Home page sections.
- `components/ui`: Reusable primitives (`Container`, `ButtonLink`).
- `lib`: Shared constants.

## Run

```bash
npm install
npm run dev
```
